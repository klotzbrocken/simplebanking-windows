# Theme-Sammlung – Windows 0.21.0

Eigene Themes werden beim Import dauerhaft in einer Sammlung gespeichert. Der vorherige einzelne eigene Theme-Speicherplatz bleibt erhalten und wird beim nächsten Import übernommen. Die Auswahl unter Einstellungen → Verhalten enthält Original-Themes und alle importierten Themes.

Unter Verwalten lassen sich eigene Themes in Hell-/Dunkelvorschau ansehen, aktivieren und entfernen. Das Entfernen des aktiven Themes schaltet auf Standard zurück. Original-Themes lassen sich nicht entfernen. Gleichnamige Importe erhalten einen Namenszusatz; vorhandene Einträge werden nicht überschrieben. Export verwendet das tatsächlich ausgewählte Paket einschließlich Grafiken und Schriften.

Fehlgeschlagenes Speichern stellt Auswahl und Sammlung im Arbeitsspeicher wieder her. Die Sammlung ist auf 20 eigene Themes und insgesamt 64 MB Grafik-/Schriftdaten begrenzt. Die bisherigen Prüfungen und Größenlimits pro importiertem Paket gelten weiterhin.

Prüfung: 112 Selbsttests einschließlich Übernahme des bisherigen Themes, Serialisierungsrundlauf mehrerer Pakete, Namenskollisionen, Schutz der Original-Themes, Speicherfehler und Sammlungsgrenzen. UI-Prüfung enthält Auswahl und Verwaltungsdialog.

Microsoft-To-Do-Registrierung und weiterer Ausbau sind auf Nutzerwunsch geparkt; die vorhandene Implementierung bleibt erhalten. Belege/Händleranbindungen und Aufrunden bleiben ebenfalls geparkt. Mac-Datenmigration ist ausgeschlossen.
