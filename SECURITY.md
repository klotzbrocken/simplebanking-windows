# Sicherheit

Bitte keine Bankdaten, IBANs, Zugangsdaten, TANs, Schlüssel oder unbereinigte Logs in öffentlichen Issues posten. Für vertrauliche Meldungen den Kontakt auf https://www.simplebanking.de/ verwenden.

Die öffentlichen Quellen enthalten keine Live-Zugangsdaten. Ausgelieferte Live-Builds können vom Herausgeber bereitgestellte YAXI-Anwendungszugangsdaten enthalten. Diese Einbettung schützt kein Secret vor Extraktion aus dem Programm. Persönliche Bankzugänge gehören ausschließlich in den lokalen Tresor.
